# Calque

Planification de section sur carte swisstopo. App web autonome : les plans restent sur le téléphone et se partagent par QR code, sans serveur.

Signes : règlement 52.003 « Signes conventionnels » (Armée suisse) redessinés en SVG, et MIL-STD-2525C (milsymbol).
