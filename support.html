Calque · Assistance

Calque est un outil de préparation pour chefs de section : carte annotée, plan horaire, moyens et liste de section. Cette page répond aux questions courantes et indique comment joindre l’éditeur.

Contact

peralex03@gmail.com

Joindre si possible le modèle de l’appareil, la version d’iOS et la version de Calque (en bas du Menu). Ne jamais envoyer de données de la troupe.

Où sont mes données ?

Sur l’appareil uniquement. Calque n’a ni compte ni serveur : l’éditeur ne voit rien de ce qui est saisi et ne peut donc pas récupérer un plan perdu. Pour en garder une copie chiffrée : Menu > Enregistrer une sauvegarde.

Passer à un nouvel iPhone

Sur l’ancien appareil : Menu > Partage et transfert > « Transférer vers un autre appareil », puis suivre les étapes sur le nouveau. Autre voie : Menu > Enregistrer une sauvegarde sur l’ancien, puis Restaurer une sauvegarde sur le nouveau.

Verrouiller Calque avec Face ID

Menu > Verrouiller avec Face ID > Activer. Calque se déverrouille ensuite comme l’iPhone : Face ID (ou Touch ID), et le code de l’iPhone si la reconnaissance échoue. Il n’y a pas de code propre à Calque. Si le code de l’iPhone est retiré, les données verrouillées sont perdues : garder une sauvegarde à jour.

La carte ne s’affiche pas

Le fond de carte vient des services publics de swisstopo (geo.admin.ch) et demande du réseau. Pour travailler sans réseau : Menu > Hors ligne > « Garder la zone hors ligne » avant de partir.

Rappels des délais

Onglet Horaire > bouton « ⋯ » > Délais et rappels > activer « Rappels », puis accepter les notifications. Les rappels sont créés sur l’appareil, même app fermée.

Statut

Calque est un outil indépendant. Ce n’est pas une application officielle de l’Armée suisse.
